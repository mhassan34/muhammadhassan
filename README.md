# Muhammad Hassan — Unreal Engine Developer

A recruiter-focused portfolio for Muhammad Hassan, covering Unreal Engine gameplay systems, UMG tools, multiplayer, Pixel Streaming, and Gaussian Splatting.

## Local development

```bash
cd portfolio-site
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The `main` branch deploys automatically to GitHub Pages through `.github/workflows/deploy-pages.yml`.
